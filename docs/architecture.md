# 架构与规则

## 技术选择

- TypeScript、React、Vite：应用界面与状态。
- chess.js：唯一的棋规来源，不自行编写走棋规则。
- Stockfish.js lite single-thread WebAssembly：本地 Worker，提供 MultiPV 分析与较高难度对手，不需要跨源隔离或服务器。
- Capacitor Android：把静态资源打包到 APK，离线运行。无远程服务地址、CDN 字体、遥测与广告 SDK。

选择 WebView 封装是为了复用成熟的离线棋规与引擎，并能在桌面浏览器快速验证同一份代码。它不是打开外部网站的浏览器壳；代码、棋子、引擎和许可证都在安装包内。

## 难度与提示

| 档位 | 名称 | 采用引擎候选的概率 | 引擎最大深度 |
| --- | --- | --- | --- |
| 1 | 第一步 / First steps | 0% | 不调用引擎 |
| 2 | 小小新手 / Beginner | 15% | 2 |
| 3 | 慢慢进步 / Learner | 35% | 3 |
| 4 | 认真思考 / Thinker | 60% | 5 |
| 5 | 小小挑战 / Challenger | 85% | 8 |
| 6 | 高手练习 / Expert | 100% | 12 |

未采用引擎时，在全部合法走法中等概率随机选择，包括升变类型。采用引擎时限制 900 ms 的搜索时间。概率与深度总体增加，但单局结果不能保证严格单调，也没有 Elo 标定。

提示不使用上述弱化策略：Stockfish `MultiPV=3`，最大深度 16，搜索时间上限 1600 ms（另有含加载在内的 20 秒失败超时）。取最深的完整 MultiPV 迭代，按排名显示去重的合法候选；合法走法少于三个时只显示实际数量。三个箭头代表不同选择，不是连续三步。

## 模块边界

- `src/game.ts`：棋局、时钟、悔棋、结束状态、保存与恢复的数据。
- `src/engine.ts`：UCI 生命周期、MultiPV 解析、超时、取消和 Worker 错误。
- `src/difficulty.ts`：六档难度，低档随机合法走子，高档逐步更多采用引擎最佳走法。
- `src/App.tsx`：界面状态与用户操作。
- `src/language.tsx`：中文 / 英文选择，默认读取系统语言，保存手动选择，支持恢复自动。
- `src/audio.ts`、`src/useAudio.ts`：Web Audio 原创旋律与事件音效，独立开关、手势解锁、暂停与后台静音。
- `src/components/`：棋盘与中英文显示等界面组件。
- `public/pieces/`：原创棋子 SVG，采用明暗渐变和轮廓，不依赖系统国际象棋字体。

## 一致性

每次走棋由 chess.js 验证。异步引擎结果只应用到它请求时的棋局；重新开局、悔棋、暂停、切后台或更换请求时取消旧 Worker，不能让旧候选污染新棋盘。分析与对战计算串行发生，不共享未完成的 UCI 搜索。

计时使用单调时钟计算实际经过时间，而不是每次 interval 固定减秒。interval 仅驱动刷新。暂停时结算本方剩余时间；首次落子开始计时。悔棋恢复落子前的时钟快照。后台自动暂停是儿童练习工具的有意设计，不适用于竞赛计时。

本地存储使用普通 JSON 版本字段和输入校验；恢复时逐手重放以保留三次重复判断。不新增 hash、冻结 contract 或额外发布门禁。

主屏高度受可用视口约束，棋盘根据剩余宽度与高度的较小值保持正方形；适配系统安全区。根页面不滚动，棋盘禁用浏览器平移手势，超过 8 CSS 像素的滑动不视为点击。棋谱只在弹窗内滚动，不使用会牵动祖先页面的 `scrollIntoView`。历史、帮助和设置内容不常驻主屏。

语言和音频分别保存在 `little-chess.language`、`little-chess.audio`，不改变已有棋局存档格式。系统语言以 `zh` 开头时选中文，否则选英文。功能文案与棋子名称只显示当前语言；许可证和原始错误诊断保留原文。

音频完全由本地 Web Audio 合成，无音频下载与授权依赖。低音量五声音阶旋律循环，落子、吃子、将军与结束用不同音列。音频上下文在首次用户操作时创建，双开关关闭时挂起；暂停、文档隐藏与原生后台事件均立即静音，回到前台后由明确操作恢复。声音设置允许试听；即使该弹窗打开，切后台也必须静音。

Android 原生监听器在页面 `load` 完成后注册。Capacitor 会在原生页面开始加载时清除插件监听器；过早注册可能在启动时丢失，造成后台计时和声音继续运行。模拟器验收必须包含冷启动后的 Home / 前台恢复与系统返回键，不能只检查网页 `visibilitychange`。
