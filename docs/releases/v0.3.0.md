# 小小棋手 v0.3.0 · 离线试用版

给初学国际象棋的孩子使用的中英双语 Android 应用。完全离线，无广告、无账户、无内购，也没有提示次数限制。

## 下载与安装

下载附件 **[little-chess-0.3.0-debug.apk](https://github.com/conanwhf/chess/releases/download/v0.3.0/little-chess-0.3.0-debug.apk)**，约 7.9 MiB，然后在 Android 设备打开安装。

系统提示时，只允许当前使用的浏览器或文件管理器安装此来源的应用。不要关闭设备整体安全保护。

这是**调试签名的试用版（Pre-release）**，不是应用商店正式版。主要目标设备为小米 Pad、Android 13。构建最低版本为 Android 7，但不代表所有系统版本和设备均已实测。

## 主要功能

- 中文和英文同时显示，棋子有立体明暗效果及双语名称。
- 人机对战、同一台设备双人轮流对战，可选择执白或执黑。
- 六档棋力，默认最低档；最低档随机选择合法走法，适合刚入门练习。档位没有经过准确 Elo 标定。
- 不限时、5 / 10 / 15 分钟、10 分钟加每步 5 秒。
- 本地 Stockfish 引擎提供最多三个推荐走法，以棋盘箭头虚拟显示，不直接代走。
- 悔棋、暂停、翻转棋盘、后台自动暂停、本地棋局恢复及棋子规则帮助。
- 支持王车易位、吃过路兵、四种升变和终局判断。

## 验证情况

- 发布前重跑：53 项单元测试、14 项 Chrome 集成测试全部通过。
- APK 签名验证通过；24 个包内应用资源与当前生产构建逐字节一致。
- 此 APK 已通过 Android 13 ARM64 平板模拟器七组验收：启动、断网提示、人机与悔棋、双人计时及后台恢复、返回键、源码附件读取、屏幕旋转。
- 未申请联网、位置、相机或存储权限；不依赖服务器或在线棋子资源。

## 已知边界

- 尚未在实际小米 Pad 验证触控、显示比例和小米系统后台管理。
- 双人模式是同机对战，不支持联网匹配。
- 难度不是准确 Elo；提示是限时引擎分析，不承诺绝对最优。
- 调试签名与未来正式发布签名不同，不能直接互相覆盖安装。
