# 小小棋手 v0.4.7 · 胜利动画与复盘试用版

## 下载与安装

下载附件 **[little-chess-0.4.7-debug.apk](https://github.com/conanwhf/chess/releases/download/v0.4.7/little-chess-0.4.7-debug.apk)**，约 7.0 MiB。

本版仍为调试签名的试用版（Pre-release），沿用此前签名，可覆盖安装同签名版本，无需先卸载。请在 Android 设备上打开 APK；系统询问时仅允许当前浏览器或文件管理器安装此来源的应用，不要关闭设备整体安全保护。

主要目标设备是小米 Pad、Android 13。最低构建版本为 Android 7（API 24），旧系统需要兼容的 WebView，不代表所有旧设备均已验证。

## 本次更新

- **胜利动画**：终局自动弹出获胜方戴皇冠的王及短暂彩纸动画，显示结果与原因；和棋显示双王。关闭后可重新查看结果，也可悔棋继续。
- **逐步复盘**：支持前进、后退、首尾跳转、进度滑块、自动播放与暂停；复盘不改原棋局和存档，退出后保持暂停。
- **面对面对弈**：双人模式下，上方一侧的棋子、名称和棋手信息朝向对面玩家，翻转和拖动保持一致。人机模式保持正向。
- **复盘文字朝向**：复盘按单人查看处理，双方棋子和名称都正向显示；退出后恢复对弈朝向。
- **记住新局难度**：确认人机开局时记住所选档位，后续新局沿用；取消选档和开始双人局不覆盖记录。齿轮仍可主动调整下一局默认棋力，不改变当前棋局。

保留离线人机、同机双人、中英文切换、点击与拖动、计时、悔棋及三个推荐候选。无广告、无账户、无背景音乐，只有事件音效。

## 验证与边界

- 发布前 100 项单元测试、80 项 Chrome 集成测试、TypeScript 与生产构建通过。
- 发布的同一 APK 在 Android 13 / WebView 109 平板模拟器覆盖安装成功，15 组验收通过，包含难度记忆、面对面对弈、复盘正向显示、胜利弹窗、离线引擎、触摸、计时和后台暂停。
- APK v2 签名验证通过；24 个包内应用资源与生产构建逐字节一致。未申请 INTERNET、位置、相机或存储等敏感权限。
- 复盘仅覆盖设备当前保留的一局，不含多局归档、评分或引擎点评。难度未标定平台 Elo。
- 「白方被将死后状态栏未更新」的反馈暂未复现，相关回归通过，但本版不宣称已修复该问题；按反馈保留待再次复现时定位。
- 仍需实际小米 Pad 试玩确认设备特有的显示、触控及后台行为。
