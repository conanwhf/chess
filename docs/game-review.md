# 终局动画与复盘

## 终局呈现

终局沿用 `src/game.ts` 的 `result()`，不新增胜负判断。白方或黑方获胜时，自动弹出对应颜色的王、金色皇冠和短暂彩纸动画；显示获胜方及将死或超时原因。和棋显示双王与和棋原因，不显示胜利皇冠。

每次进入终局只自动弹出一次，关闭后不会被时钟刷新重新打开；状态栏的「结果」可再次打开。恢复已结束存档时展示结果。悔棋退出终局后，再次结束可以重新展示。动效有限时长，系统开启减少动态效果时取消动画，保留静态结果和操作。终局音效继续遵循既有声音开关，不新增音乐。

## 复盘操作

- 从终局弹窗、齿轮设置或棋谱进入，默认显示当前棋局的起始局面。
- 按半回合前进、后退，提供回到开局、跳到最后和进度滑块。显示当前步数、总步数与 SAN 走法。
- 自动播放每秒前进一步，到末步停止；末步再次点击播放从开局重播。手动定位、退出、网页隐藏或 Android 后台均停止播放，回到前台不会自动恢复。
- 保持棋盘朝向和棋子名称设置，隐藏合法落点和推荐箭头；复盘棋盘只读，不能点击或拖动落子。
- 进入时暂停原局、停止提示和电脑计算；退出后保留原局并保持暂停，继续对弈需要明确操作。已结束棋局仍保持结束。

## 数据边界

`src/components/Replay.tsx` 使用 `initialFen` 与 `moves.slice(0, index)`，通过 chess.js 重放，正确还原吃子、王车易位、吃过路兵和升变。复盘位置与自动播放状态只存在于界面状态，不写入棋局、时钟快照或本地存档。保存的始终是完整原局，复盘中刷新也不会丢失后续走法。

不增加历史多局归档、引擎评分或变着分析。新开局仍替换当前棋局，复盘范围是设备上保留的这一局。复盘不展示历史时钟，避免把当前余时误认为每一步的实际余时。

## 验收重点

胜方颜色与皇冠一致，和棋不误显示胜者；关闭、重新开局与悔棋不导致弹窗重复。复盘首尾禁用正确，自动播放可暂停且不越界；复盘前后的原局、时钟、档位及存档一致。覆盖横竖屏、手机、中英文、减少动态效果、特殊走法以及 Android 返回键和后台停止。
