# 需求与验收

## 使用者与范围

使用者是 8 岁的初学者，初始估计 Elo 约 100；后续实际反馈为大致能下旧 Thinker 档、原生限强最低档仍过强。难度以实际试玩为准，不从这些反馈推算平台 Elo。应用优先让孩子看清棋子、正确走棋、获得不受次数限制的帮助，不提供联网匹配、账户、排行榜或 Elo 评分系统。

双人模式指同一台设备轮流走棋。主要目标设备是小米 Pad、Android 13，兼顾横屏与竖屏。APK 最低构建版本为 Android 7（API 24），同时要求 WebView 支持 WebAssembly、动态视口与容器尺寸单位；实际验收为 Android 13 / WebView 109。旧系统需要更新 WebView，不能把最低构建版本视为全部设备兼容承诺。

## 交互约定

- 同时支持点击和拖动走棋。点击棋子后显示合法目标，再点目标执行走子；按住己方棋子移动超过 8 CSS 像素后拖动，松到合法目标落子。拖动时显示跟随指针的棋子和合法目标；无效目标、棋盘外释放或取消手势均不修改棋局。鼠标和触摸共用规则，升变仍需选择棋子。
- 人机以经典 Thinker 为隐藏自动落点的分界，在十二档中的第 2 档「认真思考（经典） / Thinker (classic)」及以上不显示点击或拖动的圆点、吃子圈与合法目标边框；第 1 档与同机双人保留。以当前棋局为准，不受默认棋力修改影响。仍显示选中的棋子、上一手和将军状态，走法校验及主动提示不变。
- 棋盘手势不滚动页面，不能在电脑回合、暂停或终局拖动走子；多指触摸取消当前拖动。主屏仅显示棋盘、双方信息和时钟、状态及常用操作，完整包含在一屏内。历史、帮助、声音、翻转棋盘、名称开关、开源说明均从菜单打开。提示只在点击后显示箭头与简短候选，不常驻说明区。
- 顶部用齿轮打开设置；语言按钮显示「中 / En」，突出当前语言。
- 默认棋力单独保存在设备内，不写入当前棋局。打开新棋局时带入默认值；新棋局弹窗的临时选档仅影响该局，不反向修改默认值。
- 音效默认开启，首次用户操作后解锁音频；无事件时不发声，不提供背景音乐。暂停和切后台停止音效；声音设置可试听。音频完全本地合成，不请求网络或额外权限。
- 局中切换计时需点击「应用」，切换时按新预设重设双方时间，棋局与轮到谁走不变；选择原预设或取消不重设时间。旧计时预设下的悔棋快照同步改为新预设的初始时间，不能悔棋退回旧模式的余时。已经结束的棋局不通过切换计时恢复。
- 升变必须选择后、车、象或马，不能静默强制升后。
- 提示使用独立于对战弱化逻辑的引擎分析，不限制使用次数。
- 人机悔棋返回到玩家上一个决策位置；双人悔棋退回一手。时钟随之恢复。
- 暂停、进入设置、切换到后台时停止时钟和电脑计算。恢复需要明确点击。
- 新开局在设置弹窗确认后才替换当前棋局；配置改动不立即破坏棋局。
- 设置和棋局保存在设备内；存储失败必须显示错误，不静默掩盖。

## 已知边界

终局、复盘交互与数据约束见 [终局动画与复盘](game-review.md)。复盘只覆盖当前保留的一局，不提供多局归档或引擎点评。

- 统一十二档包含恢复的旧 3–6 级、三个经典过渡档和原生限强档，按交叉对局粗排。经典档仍包含明确的随机合法走子；这不是人类棋力模型，不能保证每档间距相同或与平台 Elo 对应。
- 提示是限定计算时间下的前三个候选，不承诺数学意义上的绝对最优。
- 不提供联网双人；不请求通知、相机、位置或文件权限。
- 首版交付可安装的调试 APK。正式签名发布需要单独准备持久签名密钥，不能把临时密钥当成正式发布密钥。
