## 0.4.0 单屏与音频修复 · 2026-11-20

旧版只检查横向溢出，没有验证主屏纵向完整显示，也未覆盖棋盘上的原生滑动。用户真机反馈后补充这些验收，不再将「无横向溢出」等同于「完整入屏」。最新界面按用户补充要求将历史与帮助移入弹窗，不保留常驻侧栏或信息页签。

| 检查 | 结果 |
| --- | --- |
| `npm test` | 63 / 63 通过，新增音效区分、关闭、暂停、释放与系统语言映射 |
| `npm run build` | TypeScript 与生产构建通过 |
| `npm run test:e2e` | 21 / 21 通过，18.3 秒，沙盒外 Chrome |
| 视口布局 | 360×640、360×800、800×1280、1280×720、1024×600、1440×1000；棋盘、双方时钟、工具栏与菜单 100% 在视口内，根页面无纵横溢出 |
| 触屏与弹窗 | CDP 触摸滑动不改变位置或棋局，点击仍可走棋；连续落子不牵动页面；长棋谱、帮助只在弹窗内滚动 |
| 语言 | 中文系统默认中文，按钮切换英文后刷新保留；恢复跟随系统，不改变局面 |

原生验收发现：页面早期注册的 Capacitor 监听器丢失，Home 后没有收到 `appStateChange`。调试器刷新和真实冷启动均可复现；页面加载完成后单独注册可收到事件。现改为 `load` 完成后注册，冷启动后的后台计时暂停、系统返回键与声音设置弹窗内后台静音均通过。没有改动 Capacitor 依赖或添加定时重试。

构建包保留在 `artifacts/little-chess-0.4.0-debug.apk`。本机 Vite 预览提供相同界面、棋规和音频的热更新调试，不需要每次安装平板。暂不推送、不发布新的 Release。

边界：尚未在小米 Pad 真机复测；音频已验证数字波形，未通过目标设备扬声器人工确认音量与音色。Android 旧版本与其他 WebView 版本未实测。
