# 测试记录

## 验证层次

1. 单元测试：合法走子、特殊规则、残局、重复局面、计时、悔棋、保存恢复、难度选择、UCI 输出解析。
2. 浏览器集成测试：真实 Worker 加载、前三候选与箭头、不改变棋局、人机与双人、设置、暂停、升变、本地恢复。
3. 视觉检查：窄手机、常见手机、平板和桌面；文字不溢出、棋子与按钮可辨认。
4. Android：Gradle 构建、APK 内容与权限检查；真机安装、WebView、触控与后台行为需要实际设备验证。
